# Installation Guide

This guide explains how to install and run the project locally.

---

## 1. System Requirements

Make sure the following are installed:

- PHP == 8.4x
- Composer
- Node.js & npm
- Python >= 3.x
- MySQL Server 8.0 & MySQL Workbench
- Git
